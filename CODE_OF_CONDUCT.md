# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By taking part in this project you agree to uphold it.

## Reporting

Report unacceptable behavior to the maintainers at `conduct@` (address TBD;
until it exists, open a private security advisory on the repository and mark
it as a conduct report). Reports are handled confidentially, and the
enforcement guidelines of the Contributor Covenant 2.1 apply.

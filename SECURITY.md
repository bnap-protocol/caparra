# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report vulnerabilities through GitHub private vulnerability reporting:
https://github.com/bnap-protocol/caparra/security/advisories/new

Include what you found, how to reproduce it, and the impact you expect. We aim
to acknowledge a report within 7 days.

## Disclosure

We follow a 90-day coordinated disclosure window. We will work with you on a
fix and publish an advisory once it is available, or after 90 days from the
report, whichever comes first. The window can be extended by mutual agreement
when a fix needs more time, or shortened if the issue is already being
exploited.

## Supported versions

The project is alpha (0.1.0-alpha, draft-00) and has not been audited.
Only the latest commit on `develop` is supported, and no release carries
security guarantees yet.

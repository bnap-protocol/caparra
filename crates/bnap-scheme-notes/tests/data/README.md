# Test data

`notes-vectors.json` holds the `bnap:notes` test vectors of
`spec/schemes/bnap-notes-draft-00.md` section 18.2 (items 1 to 9), with the
section 18.1 offers and keysets they build on. It is generated by
`../vectors.rs` with this crate as the reference encoder: the test rebuilds
every value from the inputs named in the file's `description` and compares
the result with the file, and it checks each number the spec states
(amounts, charges, selected indices, `scheme_result` sizes, scheme codes)
on its own.

Regenerate it after a deliberate change with:

    BNAP_NOTES_REGEN=1 cargo nextest run -p bnap-scheme-notes --test vectors

Section 18.1 (the notes route offer, the fee offer, keyset IDs) is published
in the spec and checked against the spec's bytes, not against this file.

This file should move to `bnap/vectors/` once the spec repository takes it;
until then it is not a published vector set. The fund quote's invoice is a
real regtest BOLT11 invoice signed by a test node key (SHA-256 of
`bnap notes test ln node`), never a payable mainnet one.
